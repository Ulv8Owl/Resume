# Подземелье запросов — SQL-тренажёр с геймификацией

Веб-приложение без сборки: открой `index.html` в браузере (нужен интернет, SQLite грузится с jsDelivr).
Запросы выполняются прямо в браузере через [sql.js](https://github.com/sql-js/sql.js), каждый раз на свежей копии базы.

## Как играть

1. Выбери комнату на карте подземелья. Каждая задача — монстр.
2. Прочитай задание и посмотри схему БД. Клик по таблице показывает её строки.
3. **Разведать** — бесплатно выполнить любой запрос и посмотреть результат.
4. **Атаковать** — сдать запрос на проверку.

## Механика боя

- Урон монстру равен тому, насколько твой результат близок к эталону: верные колонки, совпавшие строки, порядок.
  Почти верный запрос отнимает у монстра большую часть HP, а боевой журнал объясняет, что не так.
- Неверная атака — монстр контратакует (−HP). Ошибка SQL — «заклинание рассеялось», урон вдвое меньше.
- HP героя закончилось — возврат в лагерь, монстр восстанавливается, теряется 25% золота.
- Три свитка подсказок открываются по очереди. Каждый срезает добычу: 100% → 70% → 40% → 20% и снимает звезду.
- Победа без подсказок и без ран — бонус +25% золота и золотой трофей.
- Опыт повышает уровень героя (+10 к максимуму HP). Прогресс хранится в `localStorage`.

## Файлы

- `data.js` — схема и данные БД, раскладка ER-диаграммы, комнаты (задание, эталонный запрос, подсказки, награда).
- `app.js` — движок: выполнение SQL, сравнение с эталоном, бой, награды, рендер.
- `styles.css` — оформление.

Новая задача — это ещё один объект в `DUNGEON.rooms`.
