Сюда кладутся видео-награды.

Вариант 1 — зашифрованные (рекомендуется): открыть их можно только в игре по паролю.
  Оригиналы держи в папке, доступной только root, и один раз зашифруй их в эту папку:
    sudo bash tools/encrypt-videos.sh /путь/к/оригиналам ./mp3
  Здесь появятся check.js и 1.js, 2.js … 144.js. Игра спросит пароль при первом просмотре.

Вариант 2 — обычные файлы: 1.mp3, 2.mp3 … 144.mp3 (подходят и .mp4 / .webm).
  Их может открыть любой, у кого есть доступ к папке.

Эта папка не попадает в git: видео остаются только на твоём компьютере.
Когда скачиваешь новую версию игры, перенеси папку mp3 в новый каталог.
